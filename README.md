# Vanguard Roadways & Tempo Logistics — Web Application

> Complete, production-ready website for a direct fleet tempo (mini truck) and heavy truck transport & logistics business. Built with modern React, Vite, and custom industrial CSS design system.

---

## 🚛 Features

- **"Human-Made, Not Templated" Industrial Aesthetics**:
  - Deep asphalt charcoal, safety highway orange, caution stripes, and road signage typography (`Oswald` + `Plus Jakarta Sans`).
  - Alternating light and dark section rhythms with authentic commercial transport photography.
- **Docked Instant Fare & Route Estimator**:
  - Horizontal instant quoting bar in the hero with real-time distance and vehicle selection.
  - Interactive multi-vehicle calculator (Tata Ace 750kg, Bolero Maxi Truck 1.5T, 14ft Container 4T, Eicher 19ft 9T, 32ft Multi-Axle Container 20T).
  - Helper / labor counter and transit insurance toggle.
  - 1-Click WhatsApp booking with pre-formatted trip quotation and callback request modal with celebration feedback.
- **Live Shipment Tracking Engine**:
  - Search by Lorry Receipt (LR) / Docket number (Sample dockets: `VG-84920`, `VG-55102`, `VG-99231`).
  - Real-time highway telemetry, driver direct phone, and pulsing checkpoint timeline.
  - Interactive Electronic Proof of Delivery (E-POD) slip viewer.
- **Full Multi-Page Structure**:
  - **Home**: Hero, trust strip, services grid, fleet preview, direct fleet vs broker comparison table, 4-step process timeline, active corridors, testimonials, and FAQ.
  - **Services**: Detailed breakdown of 6 core services with inclusions and pricing models.
  - **Our Fleet**: Dedicated vehicle spec sheets (payload, dimensions in feet, cubic volume, deck height, suited cargo).
  - **Fare Calculator**: Full-page interactive calculation and booking wizard.
  - **Track Shipment**: Live consignment lookup dashboard.
  - **About Us**: 18-year legacy story (2008 to present), yard facilities, and safety standards.
  - **Join as Driver / Attach Fleet**: Recruitment application portal for drivers and truck owners.
  - **Contact & Yard Office**: Direct hotline numbers, WhatsApp links, regional branch offices, and coordinates.
- **Mobile-First Sticky Actions**:
  - Persistent bottom Call Dispatch and WhatsApp buttons on mobile viewports.
  - Floating WhatsApp chat button on desktop.
- **Centralized Configuration**:
  - Easily customizable business info in `src/data/transportData.js` and `src/data/fleetData.js` marked with `[REPLACE: ...]`.

---

## 🛠️ Technology Stack

- **Framework**: React 18+
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Animations**: Canvas Confetti
- **Styling**: Modular Vanilla CSS with CSS Custom Properties

## 🚀 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Intekhab-Ansari/Transport-Service.git
   cd Transport-Service
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
